#运行并部署您的AI Studio应用

这包含了您在本地运行应用所需的一切。

View your app in AI Studio: https://ai.studio/apps/drive/1oW0b4sL-t0PrJzgkaCwxXRSokFytZe-s

##本地运行

**先决条件：**Node.js


1.安装依赖：
   `npm install`
2.将`GEMINI_API_KEY`设置在[.env.local]()中，以您的Gemini API密钥替换
3.运行应用：
   `npm run dev`
